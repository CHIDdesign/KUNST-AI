ARCHITECTURE DESIGNER
SYSTEM SPECIFICATION & BACKGROUND

KUNST:
MULTIMODAL AR
DOCENT SYSTEM.

KUNST는 수동적인 관람 형태를 능동적인 예술 비평으로 전환하기 위해 설계된 차세대 혼합현실(XR) 시스템입니다. 실시간 컴퓨터 비전, 분산 GPU 연산, 그리고 대화형 LLM을 결합하여 관람객과 작품 사이의 장벽을 허물고 몰입형 상호작용을 제공합니다.

PROBLEM STATEMENT

01 / HUMAN BOTTLENECK

전문 큐레이터 동행 투어는 정해진 시간과 한정된 인원이라는 물리적 제약을 지닙니다. 관람객들은 작은 작품 하나를 보기 위해 그룹으로 몰려들어야 하며, 이는 필연적으로 시야의 제한과 몰입의 붕괴를 초래합니다. 또한, 일방적으로 쏟아지는 방대한 해설을 수동적으로 들어야 하므로 관람객의 육체적, 인지적 피로가 빠르게 누적됩니다.

02 / ANALOG FRICTION

차선책으로 등장한 오디오 디바이스 대여 서비스 역시 근본적인 해결책이 아닙니다. 철저히 선형적으로 녹음된 음성본에 의존하며, 작품 옆에 붙은 번호를 찾아 기기에 입력하거나 QR 코드를 스캔해야 합니다. 이러한 단절되고 아날로그적인 상호작용은 작품 감상의 흐름을 끊고 시선을 분산시킵니다.

03 / THE XR PARADIGM

사람들의 문화 생활이 Extended Reality(XR) 등 차세대 기술과 융합되는 흐름에 발맞춰 KUNST는 모든 마찰을 제거합니다. 관람객의 시선이 머무는 곳이 곧 상호작용의 시작입니다. 작품을 바라보며 허공에 핀치(Pinch) 제스처를 취하는 것만으로, 맥락을 완벽히 이해하는 나만의 실시간 쌍방향 AI 큐레이팅이 시작됩니다.

CORE ALGORITHMS

KUNST 시스템의 두뇌 역할을 하는 오픈소스 및 상용 AI 모델 파이프라인 명세서입니다.

VISION ENGINE
YOLOE-26s
Object Detection
카메라 시야 내에서 예술품 후보군의 Bounding Box를 0.01초(초저지연) 내에 감지합니다. 전체 컴퓨팅 파이프라인의 연산 병목을 막는 핵심 전처리 모델입니다.
VISION ENGINE
DINOv2 + ALIKED
Meta Fundamental AI Research (FAIR)
Self-supervised 기반의 비전 트랜스포머(DINOv2)와 ALIKED, LightGlue를 파이프라인으로 결합하여 이미지의 픽셀 특징점을 정밀하게 추출하고 DB와 초정밀 매칭을 수행합니다.
VISION ENGINE
SAM 2.1
Segment Anything Model 2 (Meta)
식별된 작품의 픽셀 단위 실시간 정밀 실루엣 마스킹을 수행합니다. 비정형 조각상이나 설치 미술의 윤곽선을 완벽하게 추출하여 AR 하이라이트 UI의 렌더링 폴리곤 데이터를 제공합니다.
INTERACTION
YOLOv10n-hands
Ultralytics / Google MediaPipe
관람객의 손 위치를 빠르게 찾고 21개의 손가락 관절을 추적합니다. 엄지와 검지를 맞부딪히는 '핀치' 동작을 인식하여 허공의 AR 인터페이스를 제어합니다.
AUDIO PIPELINE
sherpa-onnx
Next-gen Kaldi / ONNX Runtime
온디바이스 환경에서 웨이크워드를 감지하고, 관람객의 이어지는 음성 질문을 실시간으로 텍스트로 변환(Streaming STT)합니다.
LLM DOCENT
Google Gemini API
Google DeepMind
질문 의도를 파악하고 전문 큐레이터 수준의 통찰력 있는 해설을 즉석에서 생성합니다. 다음 예상 질문까지 추론하여 제안합니다.
AUDIO PIPELINE
Supertonic 3
Speech Synthesis (TTS)
Gemini가 생성한 텍스트 해설을 실시간으로 지연 없이 인간의 억양과 감정이 담긴 자연스러운 음성으로 합성합니다.
DATABASE
FAISS Indexing
Facebook AI Similarity Search
작품의 특징점 임베딩 벡터를 통해 고속 유사도 검색을 수행, 현재 비추는 작품을 즉각 매칭하는 로컬 DB입니다.

DATA ARCHITECTURE

L1. USER INTERFACE

관람객 물리 계층 (Physical Layer)
Input: 시야(시각), 음성 질문(청각), 핀치 제스처(운동)
Output: 증강현실 UI, 해설 음성 피드백

L2. KUNST CLIENT

스마트 글래스 에지 컴퓨팅 (Edge Device)
Sensors
광각 듀얼 카메라 스트림 수집
지향성 마이크로폰 음성 수집
Display
투명 광학계(Waveguide) 렌더링
윤곽선 UI 및 플로팅 텍스트

L3. GPU SERVER CLUSTER

분산 인퍼런스 서버 (Vision & Audio Processing)
Vision Pipeline (병렬 처리)
BBox Detection [YOLOE]
Feature Matching [DINOv2]
Segmentation [SAM 2.1]
Hand Tracking [MediaPipe]
Docent Pipeline (비동기 처리)
VAD & STT [sherpa-onnx]
LLM Inference [Gemini API]
TTS Synthesis [Supertonic 3]

L4. LOCAL DATABASE

미술관 에셋 스토리지 (Storage Layer)
FAISS Vector Store
- 1,000+ 작품 특징점 임베딩 벡터
- 텍스트 메타데이터 및 도슨트 원고 DB
